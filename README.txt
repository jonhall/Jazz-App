POETIX — iPad PWA

GitHub Pages:
1. Create a GitHub repository, e.g. poetix.
2. Upload index.html, manifest.webmanifest, sw.js and icon.svg to its root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, main, /(root), then Save.
5. Open the HTTPS Pages address on the iPad in Safari.
6. Allow microphone access.
7. Safari Share > Add to Home Screen > Add.

After the first successful visit the interface is cached for offline loading.
Microphone permission remains controlled by iPadOS/Safari.
